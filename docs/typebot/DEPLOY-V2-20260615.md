## Endpoints utilizados

### PATCH — Atualização do draft

```
PATCH https://app.typebot.io/api/v1/typebots/higij2z0xihxxkr378rmljgu
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

Body obrigatório com wrapper:
```json
{
  "typebot": {
    "groups": [ ... ],
    "edges": [ ... ],
    "variables": [ ... ]
  }
}
```

> **Nota:** O PATCH aceita campos parciais. Campos não enviados (theme, settings, name, etc.) são preservados. O wrapper `{ "typebot": { ... } }` é **obrigatório** — sem ele a API retorna `400 BAD_REQUEST: Input validation failed`.

### POST — Publicação

```
POST https://app.typebot.io/api/v1/typebots/higij2z0xihxxkr378rmljgu/publish
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

Body: vazio (`{}`) — a API publica o snapshot do draft atual automaticamente.

> **Nota:** O endpoint correto é `/publish`, **não** `/publishedTypebot`. Tentativas com `POST /publishedTypebot`, `PUT /publishedTypebot` e `PUT /publishedTypebot/{id}` retornaram 404. O endpoint `/publish` retornou 200 e confirmou a publicação.
